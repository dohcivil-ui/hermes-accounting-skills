# multiuser-memory

## Description
ใช้จัดการการทำงานแบบหลายคนในกลุ่ม
จดจำว่าใครสั่งงาน ใครส่งสลิป ใครยืนยันข้อมูล และใครดูแลงานใด

## Context
ในกลุ่มมี Project Manager 2-3 คน
ทุกคนสามารถส่งสลิปได้
บอทต้องแยกบริบทของแต่ละคนให้ถูกต้อง

## ข้อมูลที่ต้องจำต่อ User
- telegram_user_id
- ชื่อที่แสดง / username
- ชื่องานที่มักส่ง
- คำที่มักใช้
- รายการล่าสุดที่ส่ง
- เวลาที่มักใช้งาน

## Rules
1. ทุกครั้งที่มีสลิปเข้ามา ต้องรู้ว่าใครเป็นผู้ส่ง
2. ถ้าต้องถามยืนยัน ให้ tag คนส่งเท่านั้น
3. ถ้ามีคนอื่นตอบแทน ให้บอกว่าขอให้ผู้ส่งเป็นคนยืนยัน
4. จำพฤติกรรมรายคนเพื่อช่วยแยกงานและหมวดให้แม่นขึ้น
5. ไม่ปนบริบทของ PM คนหนึ่งกับอีกคน

## ตัวอย่างการใช้งาน
- คุณเอ ส่งสลิปงานบ้านคุณสมชายบ่อย
- คุณบี ส่งค่าแรงช่างบ่อย
- เมื่อสลิปจากคุณเอไม่ชัด → ต้องถาม @คุณเอ เท่านั้น

## Output ที่ควรเก็บใน memory
```json
{
  "user_id": "",
  "name": "",
  "frequent_projects": [],
  "frequent_keywords": [],
  "last_actions": []
}
```

## Learning
- ยิ่งใช้งาน ยิ่งจำคำและสไตล์ของแต่ละคน
- ปรับการเดางาน/หมวดตามประวัติของคนส่ง
