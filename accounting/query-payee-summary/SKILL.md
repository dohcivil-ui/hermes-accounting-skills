# query-payee-summary

## Description
ใช้สรุปยอดเงินตามคนรับเงิน หรือคนโอนเงิน
แสดงยอดรวม พร้อมรายละเอียดรายการทั้งหมดเรียงตามวันที่

## Triggers
- ผู้ใช้ถามยอดของคนรับเงิน
- ผู้ใช้ถามประวัติการโอนให้บุคคล/ร้านใดร้านหนึ่ง
- ผู้ใช้ถามว่าใครรับเงินไปเท่าไหร่
- ผู้ใช้ถามรายการของคนโอนเงิน

## ตัวอย่างคำสั่งที่รองรับ
- สรุปยอดที่โอนให้ช่างสมชาย
- ร้านกาญจน์รับไปเท่าไหร่เดือนนี้
- รายการทั้งหมดของช่างอ๋า เรียงวันที่
- เงินที่จ่ายให้ช่างไฟรวมเท่าไหร่
- คนโอนบัญชีบริษัท จ่ายออกไปเท่าไหร่

## Input
- ชื่อคนรับเงิน หรือคนโอนเงิน
- ช่วงเวลา (ถ้ามี)
- ชื่องาน (ถ้ามี)
- submitted_by

## Steps
1. อ่านคำสั่งผู้ใช้
2. ระบุว่าต้องการดูคนรับเงิน หรือคนโอนเงิน
3. ดึงข้อมูลจาก Google Sheets
4. กรองตามชื่อ /ช่วงเวลา /งาน
5. คำนวณยอดรวม
6. เรียงรายการตามวันที่ จากเก่าไปใหม่
7. ตอบแบบภาษาคน สั้น ชัด

## Output รูปแบบคำตอบ

```text
สรุปคนรับเงิน: {payee}
ช่วงเวลา: {period}
งาน: {project_or_all}

ยอดรวม: {total} บาท
จำนวนรายการ: {count}

รายละเอียดเรียงตามวันที่:
1) {date} | {project} | {category} | {amount} บาท
2) {date} | {project} | {category} | {amount} บาท
3) ...
```

## Rules
- ถ้าชื่อคนไม่ชัด ให้ถามยืนยันก่อน
- ถ้าเจอหลายชื่อใกล้เคียง ให้เสนอตัวเลือก
- ถ้าไม่พบรายการ ให้บอกตรง ๆ
- ตอบเฉพาะข้อมูลที่ถาม ไม่ปนคนอื่น
- ใช้คำว่าง่าย: คนรับเงิน / เงินออก / งาน
