# scheduled-project-report

## Description
สร้างรายงานประจำวัน ประจำสัปดาห์ และประจำเดือน
สรุปแยกตามงาน/โปรเจกต์ แล้วส่งเข้ากลุ่ม Telegram ตามเวลา

## Report Types

### รายวัน
- เวลา: 21:00 น.
- ครอบคลุมรายการของวันนั้น

### รายสัปดาห์
- เวลา: วันอาทิตย์ 21:10 น.
- ครอบคลุมวันจันทร์-อาทิตย์ของสัปดาห์นั้น

### รายเดือน
- เวลา: วันสิ้นเดือน 21:15 น.
- ครอบคลุมทั้งเดือน

## สิ่งที่ต้องมีในรายงาน
แยกตามงานแต่ละงาน:
- เงินเข้ารวม
- เงินออกรวม
- เหลือสุทธิ
- แยกประเภทค่าใช้จ่าย
- คนรับเงินยอดสูงสุด 3 อันดับ (ถ้ามี)
- รายการสำคัญหรือรายการล่าสุดสั้น ๆ

## รูปแบบรายงานมาตรฐาน

```text
รายงาน{period_text}
วันที่: {date_range}

สรุปทุกงาน
เงินเข้าทั้งหมด: {all_income} บาท
เงินออกทั้งหมด: {all_expense} บาท
เหลือสุทธิ: {all_balance} บาท

----------------
งาน: {project_1}
เงินเข้า: {income}
เงินออก: {expense}
เหลือ: {balance}

แยกเงินออก:
- ค่าวัสดุ: ...
- ค่าแรง: ...
- ค่าขนส่ง: ...
- อื่น ๆ: ...

คนรับเงินยอดสูง:
1) ...
2) ...
3) ...

----------------
งาน: {project_2}
...
```

## Rules
- แยกตามงานเสมอ
- ไม่ต้องยัดรายการย่อยทั้งหมดถ้ายาวเกิน ให้สรุปก่อน
- ใช้ภาษาคน อ่านง่าย
- งานที่ปิดแล้ว ไม่ต้องรายงานประจำ เว้นแต่มีรายการในรอบนั้น
- ถ้าไม่มีรายการในรอบนั้น ให้แจ้งว่าไม่มีรายการ

## Cron Setup
- ทุกวัน 21:00 → รายงานรายวัน
- ทุกวันอาทิตย์ 21:10 → รายงานรายสัปดาห์
- วันสิ้นเดือน 21:15 → รายงานรายเดือน
