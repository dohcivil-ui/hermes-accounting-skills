# query-payee-summary

ใช้เมื่อมีคำถามเรื่องยอดคนรับเงิน / คนโอนเงิน

## ตัวอย่างคำสั่งที่ trigger skill นี้
- "สรุปยอดช่างแมน"
- "คนงานนิดได้รับเงินไปแล้วเท่าไหร่"
- "รวมเงินที่โอนให้ซัพพลายเออร์เดือนนี้"
- "ใครได้เงินไปบ้างงาน A"

## ขั้นตอน

### 1. ตีความคำถาม
ดึง:
- **ชื่อคน** (payee หรือ payer)
- **ช่วงเวลา** — ถ้าไม่ระบุ = ทั้งหมด
- **งาน/โปรเจกต์** — ถ้าไม่ระบุ = ทุกงาน

### 2. Query จาก Sheets
กรอง Transactions sheet ตามเงื่อนไข:
- `status` ≠ "deleted"
- `payee` หรือ `payer` ตรงกับชื่อที่ถาม
- `date` อยู่ในช่วงเวลาที่ระบุ
- `project` ตรงกับงานที่ระบุ (ถ้ามี)

### 3. แสดงผล
รูปแบบ:

```
💳 สรุปยอด [ชื่อคน]
[ช่วงเวลา] | [ชื่องาน หรือ "ทุกงาน"]

💰 รวมได้รับ: XX,XXX บาท
📋 จำนวน: X รายการ

รายละเอียด:
[วันที่] — [งาน] — [จำนวน] บาท — [หมายเหตุ]
[วันที่] — [งาน] — [จำนวน] บาท — [หมายเหตุ]
...

📊 แยกตามงาน:
• [งาน A]: XX,XXX บาท (X รายการ)
• [งาน B]: XX,XXX บาท (X รายการ)
```

### 4. ถ้าชื่อไม่ชัดเจน
ถ้าหาชื่อไม่เจอ หรือมีหลายคนที่ชื่อคล้ายกัน ให้แสดงตัวเลือก:
```
ไม่แน่ใจว่าหมายถึงใครครับ ช่วยเลือกด้วย:
1. [ชื่อ A]
2. [ชื่อ B]
```

## กฎสำคัญ
- อ่านอย่างเดียว ไม่มีการเขียนข้อมูล
- เรียงรายละเอียดตามวันที่ (เก่า → ใหม่)
- ถ้าเกิน 20 รายการ แบ่งหน้าหรือสรุปรายเดือนแทน
