# scheduled-project-report

ใช้สำหรับส่งรายงานตามเวลาที่กำหนด แยกตามงาน

## กำหนดการ
| ประเภท | เวลา |
|--------|------|
| รายวัน | ทุกวัน 21:00 น. |
| รายสัปดาห์ | วันอาทิตย์ 21:10 น. |
| รายเดือน | วันสิ้นเดือน 21:15 น. |

---

## รายงานรายวัน

Query: Transactions วันนี้ (status ≠ deleted)

รูปแบบ:
```
📊 รายงานประจำวัน [วัน/เดือน/ปี]

[สำหรับแต่ละงาน:]
📁 งาน: [ชื่องาน]
  💚 เงินเข้า: XX,XXX บาท (X รายการ)
  ❤️ เงินออก: XX,XXX บาท (X รายการ)
  📌 เหลือสุทธิ: XX,XXX บาท

──────────────────
🏦 รวมทุกงานวันนี้
  💚 เงินเข้า: XX,XXX บาท
  ❤️ เงินออก: XX,XXX บาท
  📌 เหลือสุทธิ: XX,XXX บาท
```

ถ้าวันนี้ไม่มีรายการ → ส่ง "วันนี้ไม่มีรายการครับ 😴"

  📌 เหลือสุทธิ: XX,XXX บาท

## รายงานรายเดือน

Query: Transactions เดือนปัจจุบัน

รูปแบบ:
```
📊 รายงานประจำเดือน [เดือน ปี]

[สำหรับแต่ละงาน:]
📁 งาน: [ชื่องาน]
  💚 เงินเข้า: XX,XXX บาท (X รายการ)
  ❤️ เงินออก: XX,XXX บาท (X รายการ)
  📌 เหลือสุทธิ: XX,XXX บาท

  📂 แยกตามประเภทค่าใช้จ่าย:
  • ค่าแรง: XX,XXX บาท
  • วัสดุ: XX,XXX บาท
  • ค่าเช่า: XX,XXX บาท
  • อื่นๆ: XX,XXX บาท

  👥 Top คนรับเงิน:
  1. [ชื่อ]: XX,XXX บาท
  2. [ชื่อ]: XX,XXX บาท

──────────────────
🏦 รวมทุกงานเดือนนี้
  💚 เงินเข้า: XX,XXX บาท
  ❤️ เงินออก: XX,XXX บาท
  📌 เหลือสุทธิ: XX,XXX บาท
```

## กฎสำคัญ
- ใช้ timezone Asia/Bangkok เสมอ
- นับเฉพาะ status = "confirmed"
- ไม่นับ status = "deleted"
- แยกรายงานตามงาน ก่อนรวมยอดรวม
